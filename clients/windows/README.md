# Windows desktop (V0.5)

Double-click `Avvia ALPILAB AI.bat` from this folder (or run `python -m local_hub` from the repo root).

Requires:

```powershell
python -m pip install -r ..\..\requirements.txt
python -m pip install -r ..\..\requirements-desktop.txt
```

The window is **pywebview**, not Chrome.

Optional EXE:

```powershell
..\..\scripts\build_windows_exe.ps1
```
